# project-0
I am going to make a calculator for my very first project.



main.cpp runs my server and talks to the frontend, receiving user input expressions and sending back the solution.

calculator.cpp is my math logic. I learned Dijkstra's Shunting Yard algorithm and implemented that to achieve a correct order of operations. I've created a small helper function that establishes precedence to help me, and one that solves the postfix expression which my pemdas function made.

data_structures.cpp contains my implementations of the stack and queue data structures.

index.html and style.css are my frontend visual design.

script.js is my calculator display and button logic, as well as talking to the backend.
